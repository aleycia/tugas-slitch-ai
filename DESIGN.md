## Brand & Style

This design system expresses the intersection of tech discipline and kawaii Gen-Z feminine aesthetics tailored for female software engineering students at RPL SMKN 2 Surakarta. The visual identity bridges rigorous software craftsmanship (data structures, version control, IDE semantics) with an uplifting, warm, and hyper-cute pastel visual language.

### Personality & Demographics
- **Target Audience:** Young women studying vocational software engineering (Rekayasa Perangkat Lunak), aspiring web/mobile developers, and tech-creative high schoolers.
- **Tone:** Encouraging, expressive, playful, organized, and unapologetically feminine. It turns technical intimidation into approachable, joyful focus.
- **Visual Style:** **Kawaii-Tech Soft Minimalist Glassmorphism**. This aesthetic fuses pill-shaped geometry, milky-glass translucent surfaces, dual-tone glowing borders, micro-confetti badges, and delicate pastel gradients.

## Colors

The color palette centers around warm blush tones, baby strawberry creams, lilac highlights, and supportive functional tones tailored to a readable coding environment.

- **Primary (`#F472B6` - Soft Rose Pink):** Drives key calls-to-action, primary tags, active states, and glowing brand focal points.
- **Secondary (`#C084FC` - Lavender Mist):** Powers code badge categories, functional tags (e.g., git branches, endpoint labels), and gradient fades.
- **Tertiary (`#FBBF24` - Honey Dewdrop):** Used sparingly for alerts, streak indicators, star ratings, and code warnings without harsh aggression.
- **Neutral Canvas (`#FFF5F7` - Rose Cream):** The base backdrop replacing stark white with an ultra-soft, warm blush tint to reduce eye strain during extended coding sessions.
- **Surface & Cards (`#FFFFFF` & `#FFE4EC` / 60% opacity):** Frosted glass surfaces layered over the tinted base canvas.
- **Typography & Dark Contrast (`#4A2040` - Deep Plum Velvet):** Replaces harsh jet black with high-contrast, warm plum-slate for rich legibility and gentle visual weight.
- **Syntax Accents:**
  - String / Success: `#34D399` (Mint Macaron)
  - Method / Info: `#60A5FA` (Sky Ribbon)
  - Keyword / Accent: `#E879F9` (Fuchsia Sugar)
  - Error: `#FB7185` (Cherry Blossom)

## Typography

Typographic scale is structured around **Plus Jakarta Sans**, offering circular geometry in its bowls, open counters, and high x-height that feel friendly yet mathematically precise.

- **Display & Headings:** Rendered in Bold (`700`) and ExtraBold (`800`) weights with snug negative tracking (`-0.02em` to `-0.03em`) to anchor dashboard titles, achievement banners, and module heads.
- **Body:** Kept predominantly in Medium (`500`) and Regular (`400`) weights for relaxed readability against light pink and white surfaces. Plum Velvet (`#4A2040`) ensures minimum WCAG 2.1 AA contrast standards against pastel backgrounds.
- **Labels & Badges:** Slightly tracked out (`0.03em` to `0.05em`), set in uppercase or title-case to maintain instant clarity on tiny kawaii tag components.
- **Code Snippets & File Paths:** Paired with inline rounded mono tags (e.g. `JetBrains Mono` or `Courier Prime` at `13px`) nested within rounded pink chip containers.

## Layout & Spacing

A fluid 12-column responsive grid governs dashboards, classroom project cards, and code submission workflows.

### Grid Anatomy
- **Mobile (<768px):** 4-column layout, `margin`: `1rem` (16px), `gutter`: `1rem` (16px). Single-column card stacking with persistent pill-shaped bottom dock navigation.
- **Tablet (768px - 1024px):** 8-column layout, `margin`: `1.5rem` (24px), `gutter`: `1rem` (16px). Two-column modular grid for assignments and git logs.
- **Desktop (>1024px):** 12-column layout, max-width `1280px` centered, `margin-desktop`: `2rem` (32px), `gutter-desktop`: `1.5rem` (24px). Sidebar dock alongside flexible kanban/editor spaces.

### Spacing Model
Rhythm adheres to a predictable 4px/8px incremental base:
- Micro gaps inside badges and inputs: `space-xs` (4px) to `space-sm` (8px).
- Component inner padding: `space-md` (16px) for compact cards, `space-lg` (24px) for prominent containers.
- Section-to-section flow: `space-xl` (40px) gives generous breathing room to avoid visual clutter.

## Elevation & Depth

Visual depth avoids heavy murky drop-shadows. Instead, elevation uses **Ambient Pastel Glows** and **Milky Frosted Glass layers**.

### Elevation Scale
1. **Level 0 (Flat Canvas):** `#FFF5F7` solid foundation.
2. **Level 1 (Resting Cards & Modules):** Pure white `#FFFFFF` with 80% opacity, `backdrop-filter: blur(12px)`, bordered by a 1px solid stroke of `#FCE7F3` (Pale Blush). Shadow: `0 4px 14px 0 rgba(244, 114, 182, 0.08)`.
3. **Level 2 (Interactive Hover & Modals):** White background with a subtle strawberry gradient overlay (`linear-gradient(135deg, rgba(255,255,255,0.95), rgba(254,242,242,0.9))`), shadow: `0 8px 24px -2px rgba(244, 114, 182, 0.18), 0 0 0 1px #FBCFE8`.
4. **Level 3 (Kawaii Floating Actions & Glow Tags):** Primary gradient fill with an active ambient neon glow: `0 8px 20px 0 rgba(244, 114, 182, 0.35)`.

## Shapes

The system relies strictly on pill and continuous squircle curvature to project tenderness, safety, and modern software polish.

- **Primary Radius (`roundedness: 3`):** Full pill (`9999px`) on buttons, badge chips, status indicators, and input fields.
- **Container Radius:** Modals, code preview panels, and cards adopt generous rounded curves (`rounded-xl` / `24px` to `32px`).
- **Interactive Micro-shapes:** Profile avatars, tech stack icons (React, Laravel, Flutter), and notification pills feature circular or continuous squircles with light 2px white borders.

## Components

### Buttons
- **Primary Pill:** Background is a subtle gradient from `#F472B6` to `#EC4899`. Text is white, bold. Hover adds a glowing shadow (`0 8px 20px rgba(244,114,182,0.35)`) and shifts scale up by 1.02x.
- **Secondary Glass Pill:** Semi-translucent white (`rgba(255, 255, 255, 0.8)`), border `1.5px solid #FBCFE8`, text `#D946EF`. Hover changes background to `#FDF2F8`.
- **Ghost/Text:** Deep Plum text (`#4A2040`) with soft rose hover highlight.

### Cute Glowing Tags & Tech Badges
- **Kawaii Tech Badges:** Pill-shaped, height `24px` to `28px`. Background uses a 15% opacity tint of the respective language tone (e.g., Lavender `#F3E8FF` for PHP, Blush `#FCE7F3` for CSS). Border is `1px solid` matching the saturated accent.
- **Glowing Status Indicators:** Live build/test passes use a Mint Macaron dot (`#34D399`) with a pulsing ambient aura: `box-shadow: 0 0 8px #34D399`.
- **Specialty "RPL" Badges:** Include a tiny icon prefix (sparkle, git-branch, terminal prompt) with a micro-gradient text fill.

### Cards & Code Blocks
- **Card Container:** Outer border `1px solid rgba(244, 114, 182, 0.2)`, background `rgba(255, 255, 255, 0.85)`, backdrop blur `16px`, corner radius `24px`.
- **Code Sandbox Windows:** Header displays three pastel macro dots (Rose, Buttercup, Mint) instead of standard gray window buttons. Interior uses deep plum velvet (`#2A1625`) with pastel syntax highlighting for high-aesthetic contrast.

### Form Inputs
- **Input Fields:** Pill-shaped height (`44px`), soft blush background (`#FFF1F2`), border `1.5px solid #FCE7F3`, inner text `#4A2040`. On focus: border transforms to `#F472B6` with an outer ring glow: `0 0 0 4px rgba(244, 114, 182, 0.15)`.
- **Checkboxes & Radios:** Circle-rounded with `#F472B6` checked fill, displaying a white checkmark or heart icon glyph inside.

### Lists & Activity Feeds
- **Submission Lists:** Alternating translucent rows with rounded card separators (`16px`). Git commit entries display commit hashes inside tiny pill chips with lavender borders.
